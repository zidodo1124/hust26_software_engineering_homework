# 海蓝主题与角色形象

适用版本：0.3.2（versionCode 5），2026-10-28。本文说明界面方案、设置行为和检查范围。具体操作见[用户使用手册](user-guide.md)。

## 配色与信息层次

界面使用浅冰蓝背景、白色内容卡片与海蓝色主操作。首页统计区采用浅蓝底色，标题、数量和日期分别使用明确的字号与文字层次。角色、统计和事项列表共享同一套主题色。

蓝色表示常规操作；危险期继续使用红色，普通紧急使用橙色，完成使用绿色，逾期与归档使用灰色。状态同时保留文字提示，避免仅靠颜色或角色表情判断任务情况。按钮与选项保留触控范围，窄屏和放大字体下允许文本换行。

实现参考 [Android Compose 无障碍说明](https://developer.android.com/develop/ui/compose/accessibility)。对比度检查针对实际启用状态的文字与背景组合，不据此宣称已通过全部无障碍标准或所有设备适配。

## 两种角色形象

角色名称统一为“蓝色大肥鱼”，提供“经典立绘”和“Q 版”两种形象。经典立绘保留现有四张原图，并作为首次使用与旧版本升级后的默认值；Q 版使用独立图集。两种形象复用相同的状态判定、36 条本地台词和完成反馈，不影响事项紧急程度、提醒时间或筛选结果。

进入“设置”可预览并选择形象，点击“保存设置”后生效。未保存时返回沿用放弃修改确认；放弃后保留原选择。已保存的选择在应用重开后继续生效。

Q 版图集按原文件保存，在 IO 线程解码后提取对应表情区域，随后回收整张位图；固定图集的临时像素内存约 13.4 MiB，单帧约 156 KiB。源图片文件不改动，也不播放无关文字帧。素材出处、逐文件哈希、原作者链与许可分别见[角色素材说明](character-assets.md)。两类素材的许可范围分别说明，不能视为全网同名角色的统一授权。

## 聊天气泡与界面文案

角色名与当前状态独立显示，台词使用浅蓝底圆角聊天气泡。常规宽度下，人物在左、气泡在右，气泡尾部朝向人物；窄屏或放大字体时，人物与气泡改为上下排列，尾部朝上。尾部占用气泡自身的布局空间，正文保留内边距并按内容增长，避免遮挡相邻内容。

36 条本地台词按无待办、普通、临近截止、危险期、逾期和完成六类场景组织。语言简短自然，侧重下一步行动和适度鼓励；状态规则和稳定选择方式保持不变。气泡不提供聊天输入，也不表示接入在线 AI 服务。图片暂时不可读时，状态、台词和署名入口仍可使用。

界面说明使用统一的事项、来源、标签、完成、归档等名称。输入提示说明必填项，空列表按当前查看范围提示下一步；删除确认明确区分应用内附件副本与相册原图，提醒异常提示给出重检入口。菜单与按钮名称保持稳定，便于按用户手册操作。

## 数据与质量检查

Room schema 4 只为设置增加角色形象字段，通过显式的 3→4 迁移保留原事项、分类、附件引用、设置和通知账本；旧 schema 1、2、3 文件继续保留。未知形象值回退为经典立绘。数据库升级参考 [Room 迁移文档](https://developer.android.com/training/data-storage/room/migrating-db-versions)。

本次检查包括旧库迁移与重开、设置保存与放弃、经典与 Q 版资源的离线解码、各状态映射、主题文字对比度、窄屏及放大字体下的真实 Compose 页面。执行结果与限制单独记录在[测试记录](test-records.md)，本地渲染图不替代荣耀 X50 真机截图。

0.3.2 仅调整界面与台词，数据库仍为 schema 4，不新增依赖或数据迁移。气泡检查覆盖两种形象、320dp／150% 字体下的长文布局、图片缺失时的文字回退及真实首页渲染。锁屏／省电环境的通知补测、旧剪贴板 URI 行为继续保留为已有待验证事项。
