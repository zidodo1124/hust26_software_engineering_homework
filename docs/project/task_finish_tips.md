# 软件工程课程成果验收与实验报告要求

> 本文根据目前了解到的老师课上说明整理，最终以老师课上要求为准。

## 一、成果展示与验收

- **验收时间：最后一次课，即下周一。**
- 需要向老师展示**可实际运行的软件成果**，可以是电脑软件或手机软件。
- 可以使用视频辅助展示，但仍需提供实际运行的软件供老师验收。

## 二、选题要求

- 微信微助教发布的任务书**仅供参考**。

## 三、实验报告要求

需要编写实验报告，包含以下内容：

1. **选题**
2. **需求分析**（这个是单独的）
3. **设计文档**（这个最好也是单独的）
4. **测试报告**（这个最好也是单独的）

## 四、GitHub 仓库与提交要求

- 项目代码需上传至 **GitHub**。
- 软件实现过程中需要保留**多次提交记录及对应的修改记录**。
- 建议小组成员**按功能分工并分别提交**，体现各自负责的工作。
- **每位成员都需要有多次个人提交记录。**
- 老师明确强调：**每位成员的提交记录将作为平时分的评分依据之一。**
- 目前了解到评分会使用 AI，具体评分方式以老师说明为准。

## 五、现场提问与准备重点

演示时老师会进行提问，可能涉及：

| 提问方向 | 示例 |
| --- | --- |
| 功能与代码的对应关系 | “你演示的这个功能是由哪段代码实现的？” |
| 程序架构 | “程序整体如何组织？各模块之间是什么关系？” |
| 技术栈 | “项目使用了哪些语言、框架或其他技术？” |

各成员应熟悉自己负责的功能、对应代码，以及项目的整体架构和技术栈。
