# 五分钟功能展示速查卡

**只展示功能；源码／架构等老师在结束后提问再答。** 0.3.5／8。P＝____，S＝____，W＝____（含 S 的周内样本数）。A＝软件工程报告，B＝小组展示稿，C＝社团报名；标题前均加同一短 P。

**计时前：** 三条都待办、未归档；A 图已保存，描述无“已核对”；首页查 P 显示 3；键盘、日历、分类面板收起，已退出批量。完整 A 标题检索文本已备好。

| 时间 | 手指动作与屏幕证据 | 一句口播 |
| --- | --- | --- |
| 00:00–00:20 D01 | 指首页三条，可带过现有角色 | “把截止事项和相关材料放在一起，方便查找和安排。” |
| 00:20–01:20 D02 | 开 A→编辑描述加“已核对”→保存→详情看到新短句；字段只指认 | “修改后能在详情中确认保存结果。” |
| 01:20–01:45 D03 | 开已保存图片→关闭→返回首页 | “相关图片也保存在这件事项里。” |
| 01:45–02:15 D04 | P 改完整 A 标题，3→1；改回 P，1→3；收键盘 | “输入关键词就能找到目标事项。” |
| 02:15–03:40 D05 | 点日历→月，定位 S 所在月→月格 S=2、S+1=1→选 S 列表2→周 W→收起／重开仍 W→点 S 日2→回月选 S | “可以按月、周、日查看安排，日期数量和对应事项一起显示。” |

| 04:30–04:40 收尾 | 停在已完成 B，停止操作，不恢复 | “记录、查找、安排到完成，使用过程就展示完了。” |
| 04:40–05:00 缓冲 | 吸收前面真实延迟；没有延迟可提前结束 | 不追加功能，不主动讲源码。 |

**落后 20 秒：** 略过字段逐项指认、日历收起／重开和重复读数；仍实际保存、搜索、切日历、完成 B。未做的环节不声称做过，失败不说成功。

**终态：** B 已完成，A／C 仍待办；“已完成”选中＋B 出现是证据，摘要可仍为“S 的事项 · 1”。恢复 B、角色切换、通知、批量、“今天”或跨年，仅在结束后被问或下一轮准备时操作。

预算 **280 秒＋20 秒＝300 秒**，尚无本路线实机计时通过记录。边界在[准备清单](01-preparation.md)预先核对：同周 W=3，S 为周日 W=2；跨月分别看日期格，最后回 S 所在月。正式不展开技术限定。
