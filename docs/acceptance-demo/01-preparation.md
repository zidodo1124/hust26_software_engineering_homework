# 五分钟演示前准备清单

适用：`demo-v0.3.5`，0.3.5／8、schema 4。更新：2026-11-02。上台看[单页速查卡](03-five-minute-cue-card.md)，排练看[完整脚本](02-demo-script.md)。本页动作全部在计时开始前完成；说明书没有代替你操作手机。

## 1. 先确定前缀、日期和路线

正式路线固定为**提前建好 A／B／C，现场只编辑 A 的描述**。不安排现场新建替代路线，也不临时新增第四条主样本。

| 记号 | 含义与填写方法 |
| --- | --- |
| `P` | 本轮唯一、易输入的短前缀，例如 `D5A2`；先确认没有其他旧事项匹配它。三个标题必须用完全相同的 P，搜索时不要只输入泛用的 `DEMO` |
| `S` | A、B 的同一主日期，通常为 App 显示的北京时间今天，也可选合适的未来日期；C 在 `S+1`。尽量让两天同月、同周，减少现场翻页 |
| `a`、`b` | A、B 的未来截止时刻，b 比 a 晚 10—20 分钟，均留出完整演示余量；C 可用次日 a |
| `W` | 包含 S 的一周中，本轮样本的数量。S 与 S+1 同周时 W=3；S 为周日时 W=2，C 在下一周。排练后写在速查卡上 |
| `L` | 设置中现有“临近提醒提前分钟数”；只记录，不为主线临时更改全局提醒设置 |

若临近提醒开启，尽量让 A、B 的“截止时刻减去 L 分钟”也晚于演示结束。例：预计北京时间 20:30 开始五分钟演示，L=60，可设 A 今天 22:00、B 今天 22:15、C 明天 22:00。**时间只是示例，演示当天重新核对；不改手机系统时钟。**

临近午夜或 L 较大时，改选合适的未来日期 S，不要使用即将过期的样本。若 S 与 S+1 跨月，准备时在各自月份核对 2／1；正式 D05 先看 S+1 后，必须回 S 所在月再选择 S。S 为周日时，周历折叠前后应保持 W=2，不口述为 3。主线不点“今天”；该按钮仅在被问时演示，返回的是真实北京时间今天，不一定是 S。

## 2. 提前建好三条主样本

把下表的 P 换成真实短前缀。三条最初均为**未完成、未归档**；速通时间留空。A 的描述先不要含现场要添加的“已核对”，这样保存后能看到明确变化。

| 样本 | 标题 | 截止 | 来源 | 标签 | 提前保存的内容 |
| --- | --- | --- | --- | --- | --- |
| A | `P 软件工程报告` | `S a` | `P 课程` | `P 协作`、`P 上传` | 描述“提交实验报告与演示说明”；字段“地点”=`P-ROOM 东九楼 D105`、“提交格式”=`PDF`；1 张合成封面图 |
| B | `P 小组展示稿` | `S b` | `P 课程` | `P 协作` | 描述“核对演示分工与答辩顺序” |
| C | `P 社团报名` | `S+1 a` | `P 活动` | `P 报名` | 描述“完成社团报名并确认活动时间” |

正式 D02 只指认 A 已有的来源、标签和字段，不逐项输入；D03 只打开已经保存的图片，不启动图片选择器。

### 建立专用分类

1. 首页点 **设置 → 分类管理：来源与标签**。
2. 在 **来源管理 → 新增来源** 建立 `P 课程`、`P 活动`，每次填名称后点 **保存分类**。
3. 在 **标签管理 → 新增标签** 建立 `P 协作`、`P 上传`、`P 报名`，分别保存。
4. 点 **‹ 返回** 退出分类管理及设置。只使用本轮专用分类，不改手机原分类。

### 创建并保存事项

1. 首页点 **＋ 新建事项**，填写标题，分别点 **选择日期**、**选择时间**，按北京时间填写。
2. 速通时间留空；重要程度可按 A 高、B 中、C 低。填描述，选来源和标签；横向项目过多时左右滑动。
3. A 点 **添加自定义字段**，填写“地点”和“提交格式”两组字段，字段名称不能留空。
4. 将 A 的合成图导入后点 **保存事项**，等保存成功并进入详情。核对标题、完整时间、分类、字段和图片，再返回创建下一条。

### 合成图片必须提前导入

用画图工具制作一张普通 PNG／JPEG，例如 800×600 像素，写“软件工程报告封面／仅用于课程演示”，放入手机相册。A 编辑页点 **从相册选择**，选图，等缩略图出现，再点 **保存事项**。回详情打开缩略图，确认大图可读，然后关闭。

单张限制为 20 MiB、1 亿像素，准备图应远小于上限。若图片来源授权失败，在准备阶段重新选择；正式五分钟不处理粘贴授权、不现场挑图。不要把查看已有附件说成刚刚导入。

### 提前准备搜索输入和滚动位置

- 完整检索文本为 `P 软件工程报告`；例如 P=`D5A2`，则输入 `D5A2 软件工程报告`。它是标题中的连续文字，不需要临时拼多个条件。
- 可以在上台前把完整 A 标题复制到系统剪贴板，排练搜索框的“全选→粘贴”；恢复 P 时只输入短前缀。也可用已经熟悉的输入法直接输入，选择自己更快且稳定的方式。
- D02 的短句“已核对”手动输入；主线不复制其他字段，避免覆盖准备好的检索文本。正式中途不要离开 App 去找便签。
- 熟悉 A 的描述、保存按钮、详情附件和首页搜索框的位置；计时包含真实滚动、键盘收起和等待保存的时间。

## 3. 计时前的自检与起始画面

| 检查 | 具体动作 | 合格表现 |
| --- | --- | --- |
| 版本 | 核对 0.3.5 包；电脑保留当前资料工作分支，答问按固定标签链接看源码，无需切走资料分支 | 手机与材料一致，新说明书仍留在工作区 |
| 正常打开 | 如刚重启或强停，先打开 App，到设置检查提醒安排，再返回首页 | 没有编辑、设置、分类管理或系统弹窗残留 |
| 样本 | 首页 **待办 → 清除筛选**，输入 P | 摘要“全部待办 · 3”，只有 A／B／C；A 描述尚无“已核对” |
| 日期与周数 | 核对 S、S+1、a、b 及真实当前时刻，月格 2／1，记下 W | 截止时间仍在未来，W 与实际周范围一致 |
| 图片 | 打开 A 的已保存图片并关闭 | 图片能查看，关闭后仍在 A 详情 |
| 完成步骤预演 | B 完成一次，再在已完成中恢复为未完成 | 排练后 B 必须恢复；正式开始前三条均待办 |
| 初始 UI | 返回首页；待办、P、无来源标签限制、无日期限制；收起键盘、来源面板和日历，退出批量 | 工具按钮为“批量管理”，摘要 3，屏幕可指认首页并很快点到 A |
| 提词材料 | 打开[单页卡](03-five-minute-cue-card.md)，教学材料先备好但正式五分钟不切过去 | 手边有时间检查点，教师提问后再打开源码 |

正式预演请按 **20／60／25／30／85／50／10 秒主流程＋20 秒缓冲** 计时。没有现成的实机计时通过记录；用真实排练确认自己能否按时完成。每次排练后恢复 B，并删去 A 描述里上次加入的“已核对”，再保存，下一次才能重复展示真实变化。

以下条件只用于准备和答问，不塞进主线口播：日期格 2／1 来自 P 筛选；首页“今日 DDL”和角色取全局事项，可能包含手机原事项；点击统计卡片会清除原筛选。因此主线只指出这些入口，不点击统计卡片或要求全局数字固定。

## 4. D08 通知演示的额外准备（可选）

**不属于正式五分钟。只有演示结束后老师要求通知效果，且此前已预演成功，才使用本节。** 主线不预留等待通知的时间。

先查看保存的临近提醒开关和提前量 L；核对系统通知、提醒通道与精确／近似提醒状态。新建独立标题 `DEMO-NOTIFY-日期-轮次 通知体验`，不要包含 P。令 R 为至少 3 分钟后的整分钟，截止设为 **R+L 分钟**，速通时间留空。例：L=60，计划 20:35 提醒，截止应为 21:35；跨午夜时截止日期也要进位。

每次通知排练用新事项和新轮次。已经发过提醒的同一事项、同一截止时间，仅“重新安排”或“完成再恢复”不能保证重发；已送达记录会保留。若确实更改全局设置，先记录原值、保存修改，演示结束后恢复，并重新核对它对其他待办的影响。

重排后从设置返回 App 首页，再进入普通后台；不要留在有草稿保护的编辑／设置页。具体步骤见 [D08](02-demo-script.md#d08-可选实际通知与点击返回)。OBS-02 的重启自动恢复问题仍开放，普通后台成功不能推广到所有锁屏、Doze 或重启条件。

## 演示结束与下一轮复用

**五分钟正式结束的正确状态是：B 已完成，A／C 仍待办，屏幕显示已完成的 B。不要为了恢复三条待办而延长正式演示。**

1. 老师提问结束后，或准备下一轮排练时，再打开 B 点 **恢复为未完成**，回待办清除筛选并重输 P，恢复为 3 条。
2. 编辑 A，移除本轮增加的“已核对”并保存，核对附件、字段仍在。下一次展示前重新核对未来截止时间。
3. 若应老师要求做了归档，先从归档恢复，再按完成状态恢复；若做了通知样本，完成或清理该独立样本，使后续计划失效。
4. 恢复确实临时改过的形象或提醒设置；没有改过的保持原样。只处理明确属于本轮的演示事项，不卸载产品或清空数据。
5. 专用分类可以留作复用。若决定清理不再使用的演示事项，核对完整标题后再 **永久删除 → 确认删除**；删除不可撤销。
