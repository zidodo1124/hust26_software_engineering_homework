## 唯一正式路线：280 秒操作与收尾，20 秒缓冲

| 累计时间 | 编号与动作 | 要让老师看到的结果 |
| --- | --- | --- |
| 00:00–00:20 | D01 首页定位 | 已准备的三条样本；可顺带指出现有角色，不进入设置 |
| 00:20–01:20 | D02 打开 A，编辑描述加“已核对”，保存 | 返回详情后真实出现新短句；分类、字段只指认已准备内容 |
| 01:20–01:45 | D03 打开已保存的图片，关闭并返回首页 | 附件能查看，回到三条待办 |
| 01:45–02:15 | D04 标题关键词搜索 | 样本结果 **3→1→3**，最后恢复 P 并收起键盘 |
| 02:15–03:40 | D05 月格→选 S→周→收起／重开→点 S 进入日→回月选 S | 月格 **2／1**，单日 **2**，收起／重开保持本周数量，日视图 **2** |
| 03:40–04:30 | D06 打开 B 标记完成，返回待办，再切已完成 | S 待办 **2→1**；“已完成”入口下能找到 B |
| 04:30–04:40 | 一句功能闭环收尾，停止操作 | 留在能看到已完成 B 的页面，不恢复、不加新功能 |

时间合计为 **20＋60＋25＋30＋85＋50＋10＋20＝300 秒**。这是编排预算，**尚未完成这一套五分钟路线的实机计时预演**；请自行走一遍并计时。提前结束正常，不为凑满时间追加功能或讲源码。

三条样本、图片、来源、标签和字段全部提前准备。正式主线不现场新建事项、挑图、建分类、复制字段、切换角色样式或等待通知；恢复、归档、批量、“今天”和跨年等只在五分钟结束后，老师要求时才展开。D01—D09 编号仍与教学材料一致，D07—D09 属于答问备查。

## 起点、终点与落后处理

- **开始前：** A／B／C 全部未完成、未归档；首页为待办，查询 P，摘要“全部待办 · 3”；键盘、来源面板和日历收起，已退出批量。
- **正式结束时：** B 留在已完成，A／C 仍未完成。页面可保持“已完成”选中且显示 B；**不要求回到三条待办**。恢复 B 是演示结束后的工作。
- **落后 20 秒：** 优先省掉分类／字段逐项介绍和日历收起／重开这一组来回；仍保留真实保存、3→1→3 搜索、实际日期结果和完成状态变化。只说已经实际看到的结果，详见[脚本裁剪规则](02-demo-script.md#时间落后或步骤失败时)。
