## 1. 目标、范围与来源

用户需要把来源不同的事项集中整理，通过来源、标签、关键词快速找到目标，并为不同事项保存各自的地点、联系人等附加文字。本模块负责这些信息的含义、维护方式、检索结果和数据保留要求。

主文档为[需求分析](requirements.md)。本稿补充其第 6.1、6.4 节及 AC-12、AC-13，不另建与主文档冲突的产品范围。规则发生变化时，应同步主文档及后续设计、测试追踪。

| 依据 | 可支持的结论 |
| --- | --- |
| 主文档 S-01、S-04、S-05 | 事项支持来源、标签、关键词筛选和截止时间排序；文本字段属于每个事项，可查看、编辑和复制 |
| 2026-10-30 付泽文直接答复，主文档 S-10 | 同类分类名称去首尾空白、不区分英文大小写判重，来源与标签间可同名；多个标签全部满足，其他筛选条件取交集；同一事项允许同名字段，内容可空 |
| 2026-10-30 付泽文对五组摘要答复“确认可以” | 确认分类停用保留旧关联及恢复后重新使用、搜索标题／描述／字段名和内容、字段名非空及添加顺序、取消／失败保留原数据与升级保留关联、暂不指定数量与性能数值；不等同逐项确认未在摘要中提及的全部细节 |
| 主文档既有待审建议及本轮流程分析 | 停用与恢复、重名覆盖范围、搜索字段、相同截止时间顺序、异常与持久化的细化建议 |

当前代码只用于发现需要写清的边界，不作为用户已经确认产品规则的证据。本轮不修改生产代码、数据库结构或自动测试，不根据旧测试结果预填本稿验收通过。

## 2. 术语与规则

| 编号 | 需求细化 | 状态及理由 |
| --- | --- | --- |
| DR-01 | 一个事项可不选来源或选择一个来源，可不选标签或选择多个标签；来源与标签由用户维护，不锁定为“学习／生活”等固定枚举 | 待审核建议：明确单选与多选及空选语义 |
| DR-02 | 来源名、标签名去除首尾空白后不能为空。同类名称不区分英文大小写判重，来源与标签之间允许同名；内部空格不额外合并，不执行拼音、简繁或语义相似判重 | 判重方式与跨类同名已由付泽文确认；非空及内部空格边界为待审核建议 |
| DR-03 | 新增及改名均检查同类重名，停用项仍参与判重；修改某项自身而未改变名称不算重复。改名后关联事项显示新名称，不改变所属事项和关联关系 | 待审核建议：避免通过停用绕过判重，保证改名可理解 |
| DR-04 | 本版分类维护采用新增、改名、停用、恢复，不提供永久删除分类。停用不删除事项或旧关联；旧事项可继续显示并保留停用关联，但不能给其他事项新增该关联。移除停用关联后再次添加，应先恢复分类；停用项仍可用于查找旧事项 | 付泽文已确认停用保留旧关联、其他事项不能新增、恢复后可使用；是否提供永久删除及停用项检索等其他细节待审核 |
| DR-05 | 自定义字段是事项独立的“名称＋文本内容”，可添加、修改、移除、查看和复制。不同事项的同名字段互不影响；同一事项也可有多个同名字段，分别保存和操作；内容允许为空 | 每事项独立及基本操作来自既有已确认需求；同事项同名、内容可空已由付泽文确认 |
| DR-06 | 字段名称去首尾空白后不能为空，内容按用户输入保存，不自动去掉正文空白；字段按用户添加的顺序展示，改名和改内容不改变顺序。只提供文本，不支持字段类型、字段模板或跨事项自动继承；本版不新增拖动排序承诺 | 付泽文已确认字段名非空、内容可空及添加顺序；是否保留正文空白、修改后的顺序等细节待审核；文本及无模板来自既有需求 |
| DR-07 | 关键词去首尾空白后，对标题、描述、字段名称和字段内容做不区分英文大小写的连续子串匹配，任一位置命中即匹配。空关键词不限制结果；多个词按一个完整字符串处理，不做分词、拼音、模糊或 OCR 检索；来源名和标签名通过分类筛选选择，不自动纳入关键词搜索 | 付泽文已确认四类搜索字段、来源和标签通过筛选选择；空关键词、大小写、连续子串及多词等细节待审核 |
| DR-08 | 所选来源、关键词、日期、危险期及列表模式等条件同时满足才返回事项。选择多个标签时须全部具有；无标签条件不限制标签，无来源条件不限制来源。清除筛选不修改事项内容 | 多标签全部满足及条件取交集已由付泽文确认；空条件与清除行为为待审核建议 |
| DR-09 | 默认待办不显示已完成及归档项，过期未完成项仍保留；已完成列表不重复展示归档项，归档列表可包含已完成项。各列表内部按截止时间升序，时间相同保持可重复的稳定顺序；日历按北京时间日期筛选。筛选结果数量对应当前结果，首页“今日／危险期”统计保持其自身全局范围 | 默认待办、完成与归档基本规则来自既有需求；列表交叉范围、稳定顺序及统计与筛选边界为待审核建议 |
| DR-10 | 编辑成功后，分类关联、字段和当前检索结果应一致；正常退出并重开仍能读取。取消未保存编辑不改变旧数据。旧编辑不能覆盖其打开后已经发生的新修改，保存失败不能显示成功或丢失原有完整数据 | 付泽文已确认取消或保存失败保留原数据；旧编辑冲突和失败提示细节待审核；退出重开来自 FR-15 |
| DR-11 | 应用覆盖升级须保留已存事项、来源标签、字段、附件关联及设置；不得通过清空数据库让升级成功。永久删除事项时清理其关联与字段，不删除其他事项及共享分类目录。字段和分类维护不改变事项截止时间、完成或归档标记 | 付泽文已确认升级保留事项、分类、字段和附件关联；设置、删除及维护操作的具体边界待审核 |

上述规则不规定 SQL、主键和具体接口；对应实现方案在需求审核后核查[设计文档 D-02／D-04](design.md)。schema 当前为 4，后续需核查 1→2→3→4 的兼容链，不能把旧任务文件中的 schema 3 当作当前版本。
