## 首页与提示怎么说

首页主标题采用用户提出的 **“今日事，今日毕”**。鲸鱼娘像同学一样提醒两句，按钮和错误提示则直接说明要做什么。

- **角色台词用短句。** 少说“从容安排”“按自己的节奏推进”这类套话，也不责备、卖惨或反复催促。
- **功能名说清楚。** “保存事项”“标记完成”“归档”“删除”各有含义，不为了活泼而混用。
- **出错时说原因和办法。** 能重新选图、重新打开或去设置处理，就把下一步写出来；不能保证解决的情况不打包票。
- **必要信息不能省。** 权限是否开启、提醒可能延迟、图片限制、重复事项的修改范围，以及删除后能否恢复，都要保留。刚完成一项不能说成全部做完，逾期也不能说成一定能补交。

## 常用提示前后对照

| 场景 | 原来 | 现在 |
| --- | --- | --- |
| 首页主标题 | 重要的事，提前安排。 | 今日事，今日毕 |
| 没填标题 | 请填写事项标题。 | 给事项填个标题吧。 |
| 没写描述 | 暂无描述，可在“编辑事项”中补充。 | 还没写描述，点“编辑事项”可以补上。 |
| 图片网址 | 请选择或粘贴可读取的图片，图片网址不能直接作为附件。 | 图片网址不能直接添加，请选择或粘贴图片本身。 |
| 退出归档 | 恢复归档 | 移出归档 |
| 重新检查通知 | 重新检查并安排提醒 | 检查并安排提醒 |
| 临近颜色设置标题 | 普通紧急程度 | 临近截止 |
| 保存失败 | 操作未完成，请重试。当前填写的内容已保留。 | 操作没成功，填写的内容还在，可以再试一次。 |

日期仍注明北京时间，图片仍限制单张 20 MiB、1 亿像素；重复事项不支持图片。删除说明按当前可用操作区分，已完成或归档的重复事项只说明删除本次。图片的空提示也限定普通事项，避免把不可用的入口说成可用。

## 鲸鱼娘的六组台词

下面每组六句，共 36 句。台词按现有规则轮换；这次改词没有改变状态判断、轮换方式或角色图片。

### 没有待办：暂时没待办

1. 这会儿没待办，歇会儿吧。
2. 清单空着呢，空闲时间留给自己。
3. 有新安排了，记在这儿就行。
4. 趁现在有空，想想接下来要做什么。
5. 先去忙别的，有新任务再记。
6. 暂时没事要赶，做点喜欢的事吧。

### 正常待办：先做一件

1. 先挑一件，做一点算一点。
2. 开工前看清要求，省得返工。
3. 先忙最要紧的，其他的慢慢来。
4. 记得给检查和上传留点时间。
5. 今天多做一点，最后一天少赶一点。
6. 不好下手的话，先拆成几件小事。

### 临近截止：快到点了

1. 快到点了，看看还差什么。
2. 该收尾了，附件和提交入口也看一眼。
3. 先把要交的做完，细节待会儿再改。
4. 交之前看一眼格式，附件别漏了。
5. 别急，先把手上这一步做完。
6. 快截止了，别把上传拖到最后一刻。

### 进入速通危险期：该冲刺了

1. 到冲刺时间了，先忙这件吧。
2. 时间不多了，先做出能交的版本。
3. 先把最要紧的做完，细节有空再改。
4. 先别分心，忙完手上这一步。
5. 忙归忙，别忘了上传后确认一下。
6. 别慌，先把最关键的部分做完。

### 已经逾期：有事逾期了

1. 这件事过点了，看看还能不能补交。
2. 有件事逾期了，点开看看怎么处理。
3. 还能不能补交？找负责人问问吧。
4. 先别急，看看还有什么能补救。
5. 这件事还留着，处理好再完成或归档。
6. 能补的先补上，再忙下一件。

### 刚完成一项：又搞定一件

1. 又搞定一件，辛苦啦！
2. 少了一件待办，歇口气吧。
3. 这件事忙完了，休息一会儿。
4. 做完啦！要交的东西，记得看看交上没有。
5. 又做完一件，今天没白忙。
6. 这一项记为完成了，接着忙还是歇会儿？
