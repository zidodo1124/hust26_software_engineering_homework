# Bundled whale-girl artwork

HUSTer's DDL Saver bundles four nonofficial whale-girl illustrations from
[JAdpp/dsh-whale-galgame](https://github.com/JAdpp/dsh-whale-galgame), pinned to
commit `046b848f244450e6e636335766276bf3343fe84b`.
