## 记录方式

- 文件路径使用 `参与者/YYYY-MM-DD.md`；同一天的新交互继续追加到对应文件。
- 用户记录中分别标明发言人和 AI 助手回应；AI 目录概括其实际辅助工作，便于分辨各自承担的内容。
- 历史记录为内容摘要，不是逐字聊天导出。2026-10-27／28 旧记录时间基准为 `America/Los_Angeles`，原样保留；付泽文 2026-10-30／31 的记录采用 `Asia/Shanghai`（UTC+08:00）。各文件明确其时间基准，缺少准确时分时写明“具体时分未记录”，使用顺序编号，不推测发送时间。
- 整理时间与消息时间分别标注。仅有日期的旧消息不会因为后续整理而获得虚构的精确时间。
- 需求选项确认、文档整体审核和实际实现分别记录；最终审核结论见[审核与修改记录](../docs/review-log.md)。
